I coded a full QR Code Generator because I wanted to learn about error correction and QR Codes, all in C++, with the help of [Nayuki](https://www.nayuki.io/page/qr-code-generator-library)'s code.

I then tried to embed pictures inside QR Codes thanks to their error correction and I got some interesting results as you can see on the attached picture.

The code can be found here: <https://github.com/Axelgoris99/QR_Embed>
