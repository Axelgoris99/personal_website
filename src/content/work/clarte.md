Worked to create a quick interface prototyping tool with visuo-haptic co-location and eye tracking using a mixed reality see-through headset.

Created a co-location algorithm to align real and virtual objects.

Created a post-processing shader to generate a high-quality heatmap by using eye-tracking on the user.
